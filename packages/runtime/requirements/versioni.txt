# Le versioni che abbiamo provato. Questo file è la legge dell'ambiente.
#
# ─────────────────────────────────────────────────────────────────────────────
# COS'È
#
# Un file di **vincoli** (`uv pip install --constraint`), non di requisiti: non
# installa niente da solo. Dice soltanto che, se qualcuno installa uno di questi
# pacchetti, deve essere *questa* versione. Vale per tutto ciò che entra
# nell'ambiente condiviso:
#
#   - le librerie comuni (`base.txt`)
#   - i motori nostri (`services/<id>/requisiti.txt`)
#   - il `requirements.txt` di **ComfyUI**, che non abbiamo scritto noi
#   - i `requirements.txt` dei **nodi custom**, idem
#
# Le ultime due sono la ragione per cui questo file esiste e per cui non basta
# scrivere `==` dentro i nostri requisiti: il codice di terzi dichiara le sue
# dipendenze come gli pare, e senza un vincolo comune è lui a decidere che
# versione di `transformers` si ritrova in casa DaProdDream.
#
# ─────────────────────────────────────────────────────────────────────────────
# PERCHÉ
#
# L'ambiente Python è **uno solo per sei app**. È quello che ci fa stare in
# 4 GB invece di 14,7, ed è anche il posto dove installare un'app può rompere
# le altre senza toccarle.
#
# Il 19 agosto 2026 è successo: dopo aver installato DaProdIoDigitale, Musica e
# Foto non si aprivano più e Dream e IoDigitale si aprivano senza funzionare.
# Nessuna delle quattro era il problema. Due librerie continuavano a rimbalzare
# avanti e indietro a ogni installazione — una le voleva nuove, un vincolo
# scritto mesi prima le voleva vecchie — e ogni rimbalzo è una disinstallazione,
# cioè un'occasione perché l'antivirus la spezzi a metà (l'errore 4395 che
# `uv.ts` sa aggirare, ma non sempre). Alla fine `huggingface_hub` è rimasto
# mezzo installato: `errors.py` della 0.36 accanto a `utils/__init__.py` della
# 1.28, con tutti i numeri di versione giusti e i file di due versioni mescolati.
#
# Con i numeri fermi non c'è più niente che rimbalzi: niente rimbalzo, niente
# disinstallazioni, niente occasioni.
#
# ─────────────────────────────────────────────────────────────────────────────
# COME SI CAMBIA
#
# A mano, quando lo decidiamo noi, e riprovando le app dopo. È la stessa regola
# di ComfyUI (versione fissata in `motore.ts`) e dei nodi custom (commit fissato
# in `nodi.ts`): si aggiorna perché abbiamo deciso di aggiornare, non perché era
# martedì e su PyPI è uscita una versione nuova.
#
# **Se un'installazione fallisce con «no solution found»** è questo il file da
# guardare: vuol dire che qualcosa di nuovo pretende una versione diversa da
# quella che abbiamo provato. Quello è il momento di decidere — alzare il numero
# qui e riprovare i motori — e non un incidente da aggirare togliendo il vincolo.
#
# I numeri qui sotto sono letti dall'ambiente di Cammo il 19 agosto 2026, quello
# su cui girano tutti e cinque i motori.
#
# **torch non è in questo elenco, di proposito**: la sua versione giusta
# (`2.13.0+cu130` su una NVIDIA, `2.13.0` su sola CPU) dipende dalla macchina,
# e nessun codice di terzi può toccarlo comunque — `requisiti.ts` lo toglie
# dalle liste altrui prima ancora che uv le veda.
# ─────────────────────────────────────────────────────────────────────────────
