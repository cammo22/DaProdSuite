# Base condivisa da tutti i servizi della suite.

# Qui va solo ciò che serve davvero a tutti. Le dipendenze specifiche di un
# motore (diffusers per Dream, i pacchetti di ComfyUI per Musica e Foto, quelli
# di SoulX per IoDigitale) stanno nel requirements del rispettivo servizio: così
# chi installa solo il Visualizer non si porta dietro mezza libreria di computer
# vision.
#
# torch NON è qui: si installa a parte con --torch-backend=auto, perché la wheel
# giusta dipende dal driver CUDA della macchina.
#
# **I numeri esatti non stanno qui, stanno in `versioni.txt`**, che è il file di
# vincoli applicato a *ogni* installazione della suite — comprese quelle di
# ComfyUI e dei nodi custom, che non abbiamo scritto noi. Questo file dice
# **cosa** serve; quello dice **in che versione**, una volta per tutti.
